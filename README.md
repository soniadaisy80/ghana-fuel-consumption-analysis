# fuel-consumption-ghana
Overview
This project examines fuel consumption trends in Ghana and their relationship with:

Inflation
GDP Growth
CO₂ Emissions

Tools Used
Excel
Python
Power BI

Key Findings
Petrol and diesel consumption are associated with higher CO₂ emissions.
LPG shows a positive relationship with GDP growth.
Fuel consumption has varying relationships with inflation.
